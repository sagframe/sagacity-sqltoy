## 🟢 低优先（编写方式/健壮性，可选）

- **空 catch 无注释**：DialectUtils:3461,3467、DefaultDialectUtils:986-991、BeanUtil:209-211、SqlExecuteStat:127,150,175
- **System.out 残留**：SqlExecuteStat.java:277（debug 开启时整段报告打 stdout，应走 logger）
- **DefaultOverTimeHandler:29,95**：比较器 long 差值截断 int（慢SQL排序违反契约），应 Long.compare
- **SqlToyConfig.clone() 返回 null**（599-602）：调用方直接使用会 NPE
- **getDialectSql containsKey→get→put 非原子**（723-729）；PageOptimizeUtils 锁内双查（130）；convertFieldsToColumns 双查+动态SQL缓存污染（2682）；EntityManager.parseEntityMeta 全方法 synchronized+双查（259）
- **Locale.ROOT 缺失**：BeanUtil 等 30+ 处无参 toLowerCase/toUpperCase（土耳其语环境属性匹配失败）
- **复制漂移风险**：merge using select 段在 DialectUtils 与 DialectExtUtils 两处逐行重复（约80行）；TidbDialect≈MySqlDialect 等整类复制（修bug需N处同步）；OracleDialect 的 IDENTITY→SEQUENCE 逻辑同类内重复5次
- **超长方法**：getSaveOrUpdateSql（300行）、loadAll（320行）、setParamValue（370行）、mergeIgnore（244行）、updateSaveFetch（230行）
- **杂项**：toSqlString/toSqlLogStr 60行近似复制；SqlToyConstants.filters 公开静态可变 Map + 双花括号初始化；SqlScriptLoader 缓存满后永久不缓存；ResultUtils 的 `Boolean x = (y.isEmpty()) ? false : true` 无谓装箱（3处）
